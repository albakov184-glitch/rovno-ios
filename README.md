# Ровно

Учёт доходов и расходов с аналитикой для iPhone. Стеклянный интерфейс в духе iOS, три экрана:

- **Обзор** — остаток за месяц (цифры прокручиваются), доходы и расходы, доля отложенного, последние операции, главные траты.
- **Операции** — поиск, фильтр «Все / Расходы / Доходы», список по дням. Свайп влево удаляет, нажатие открывает для правки.
- **Аналитика** — кольцевая диаграмма по категориям (нажмите на категорию), расходы по дням, доходы и расходы за полгода.

Добавление — кнопка «+»: своя цифровая клавиатура, категории, заметка и дата. В приложении работает вибрация (Haptics), данные хранятся на iPhone (Capacitor Preferences).

## Как получить IPA

Каждый push в `main` запускает **Actions → Build IPA** на macOS. Через 5–10 минут готовый файл появляется в двух местах:

1. **Releases → «Ровно (последняя сборка)» → `Rovno.ipa`** — удобно открыть прямо с iPhone.
2. **Actions → последний запуск → Artifacts → `Rovno-ipa`** (скачивается zip, внутри IPA).

Собрать вручную: **Actions → Build IPA → Run workflow**.

IPA неподписанный. Подпишите его своим сертификатом (ESign, Scarlet, Sideloadly, AltStore) и установите.

## Как устроен проект

```
src/app.html               всё приложение: разметка, стили, логика
scripts/build-web.mjs      собирает web/index.html для iOS из src/app.html
capacitor.config.json      название, bundle id (app.rovno.finance)
ios/App/                   проект Xcode (Capacitor 8, Swift Package Manager)
.github/workflows/         сборка IPA
```

Локально (нужен Mac с Xcode):

```bash
npm ci
npm run ios:sync   # собрать web и скопировать в iOS-проект
npm run ios:open   # открыть в Xcode
```

Чтобы поменять иконку, замените `ios/App/App/Assets.xcassets/AppIcon.appiconset/AppIcon-512@2x.png` (1024×1024, без прозрачности).
