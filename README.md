# Ровно

Учёт доходов и расходов с аналитикой для iPhone, в стиле iOS.

- **Обзор** — остаток за месяц, доля отложенного, прогноз на конец месяца, бюджет с суммой «можно тратить в день», подсказки, цели, последние и ближайшие платежи.
- **Операции** — поиск, фильтры по типу и категории, список по дням. Свайп влево удаляет (с отменой), нажатие открывает для правки и повтора.
- **Аналитика** — месяц или год: кольцо по категориям, темп трат против прошлого месяца и бюджета (проведите пальцем по графику), календарь трат, столбики по месяцам, рейтинг категорий с динамикой, средние и рекорды.
- **Ещё** — бюджет общий и по категориям, цели-копилки, регулярные платежи (записываются сами), свои категории, 15 валют, тема, скрытие сумм, код-пароль, экспорт в CSV, резервная копия и восстановление.
- Добавление — калькулятор (250+180), частые операции в одно касание, «каждый месяц», вибрация.

## Две версии

| | Офлайн | Онлайн |
|---|---|---|
| Файл | `Rovno-Offline.ipa` | `Rovno-Online.ipa` |
| Название на iPhone | Ровно | Ровно Онлайн |
| Интернет | не нужен совсем | нужен для обновлений |
| Обновления | новый IPA | сами, при каждом запуске с сайта |
| Без интернета | работает | открывает встроенную копию |

Данные в обеих версиях хранятся на iPhone. У каждой версии свои данные: перенести их можно через «Ещё → Резервная копия» и «Восстановить из копии».

Сайт (он же источник обновлений для онлайн-версии): https://albakov184-glitch.github.io/rovno-ios/ — его можно добавить на экран «Домой» из Safari, он тоже работает офлайн.

## Как получить IPA

Каждый push в `main` запускает **Actions → Build IPA**. Через 10–15 минут:

- **Releases → «Ровно» → `Rovno-Offline.ipa` и `Rovno-Online.ipa`** — удобно открыть прямо с iPhone;
- сайт обновляется в ветке `gh-pages`.

IPA неподписанные. Подпишите своим сертификатом (ESign, Scarlet, Sideloadly, AltStore) и установите.

## Как устроен проект

```
src/shell.html             разметка
src/styles.css             стили
src/app.js                 логика
scripts/build-web.mjs      собирает web/ (iPhone и сайт) и dist/artifact.html
capacitor.config.json      название, bundle id (app.rovno.finance)
ios/App/                   проект Xcode (Capacitor 8, Swift Package Manager)
.github/workflows/         сборка IPA
```

Локально (нужен Mac с Xcode):

```bash
npm ci
npm run ios:sync   # собрать web и скопировать в iOS-проект
npm run ios:open   # открыть в Xcode
```

Чтобы поменять иконку, замените `ios/App/App/Assets.xcassets/AppIcon.appiconset/AppIcon-512@2x.png` (1024×1024, без прозрачности).
